# Welcome to Gaze!
Your new favorite API to make *your* avatars more lively!

Gaze is a super expressive API that allows you to animate your avatar while reacting to the environment around it.
## Installing
Simply download the `Gaze.lua` file to your avatar and require it!
You can get `Gaze.lua` in: [Releases](https://github.com/Bitslayn/Gaze/releases/latest) or [Direct Download](https://github.com/Bitslayn/Gaze/blob/main/Gaze.lua).

```lua
local gaze = require("Gaze")
```

For configuration look at our [Wiki](https://github.com/Bitslayn/Gaze/wiki) or [Get The Examples](https://github.com/Bitslayn/Gaze/releases/latest). :D
